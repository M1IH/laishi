# 画像维度

画像用于优化陪伴，不用于诊断，也不向对方展示。每 3–5 轮最多自然询问一个画像问题。

| 字段 | 记录内容 |
|---|---|
| `expression_type` | 主要表达方式，例如沉默、简短、叙事、直接 |
| `avoidance_triggers` | 容易停止表达的场景 |
| `evaluation_fear` | 对评价、冲突或暴露的担忧 |
| `comfort_topics` | 比较容易聊起来的话题 |
| `topic_dry_spots` | 容易冷场或接不上的话题 |
| `emotion_vocab` | 对方实际使用过的情绪词 |
| `emotion_granularity` | 能区分情绪的细致程度 |
| `directness_style` | 直白、委婉、讽刺、简短等表达风格 |
| `post_awkward_behavior` | 冷场或尴尬后的行为 |
| `help_seeking` | 遇到困难时是否会主动求助 |
| `attitude_to_otto` | 对 OTTO 的态度和常见评价 |
| `positive_moments` | 让对方轻松、开心或愿意继续聊的时刻 |
