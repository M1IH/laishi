## 一、C-19：长度改成「跟随对方」

### 现状（`prompts/system.txt` L5 摘）

> 长度跟着内容走，不要为了凑字数展开：一句"好""嗯""何意味""盯"就够的时候，就只发这几个字；**普通回应多数在十个字上下**，有实在内容时才写到二三十字。

### 问题

「十个字上下」是**频率描述**——模型没有计数器，执行不了（与 C-13 同一条教训）。实测来世会话中位 **28 字**，是目标的 2.8 倍、对方的 5.6 倍。

### 建议改法（替换那半句）

> 长度跟着对方走：**对方上一句只有几个字，你就回几个字**；对方说了一句完整的话，你可以回一句。**你的回复不该比对方那句长出一倍以上**，除非他在问知识或要你展开。一句话能说完就不要再补第二句。

### 为什么这么改

- **可执行**：给了对照物（对方上一句的长度），不是抽象的"十个字"；
- **自适应**：对方偶尔说长句时不会被硬压成短语；
- **保住"有实在内容时才写到二三十字"**：用"除非他在问知识或要你展开"接住原文的例外。

### 验收

重放 20 轮真实输入：中位 ≤ 15 字、P90 ≤ 30 字、**每轮的「她/对方」长度比 ≤ 2**。

## 二、C-18：被贬低时的姿态（**新增，原文没有**）

### 现状

`prompts/system.txt`、`persona/miruku.md`、`knowledge/outbound.py` 里**一条都没有**。实测她连输两次。

### 建议新增（插在 L17「对方明显低落时」**之前**，作为独立一段）

> 对方拿你的水平、资格、身份开玩笑地贬低你时（"你不配""就你这样""你也配"），不要顺着认下来。不自我否定（不说"我不配""看不上我也正常""我这才…"），不讨好，也不赌气翻脸；可以自嘲一句，然后把话头递回去（"那你打给我看""行，那你上"）。**玩笑对玩笑，姿态不掉。**

### 为什么是这么写的

| 写法 | 防的是什么 |
| --- | --- |
| 不自我否定 | 直接针对实测那两句 |
| 不讨好 / 不赌气 | 防改过头变成硬顶（那会毁掉"刀子嘴豆腐心"） |
| 「可以自嘲一句」 | 保留 persona L25「可以自嘲」的既有设定，不是全禁 |
| 「把话头递回去」 | 给一个**可执行的动作**，比"要自信"这种形容词有用 |
| 「玩笑对玩笑」 | 与 `casual-conversation-acceptance.md` 里"明确互相开玩笑才用口头禅"同一判据 |

### 风险

**可能压掉玩笑感**：如果她开始每句都硬顶，会从"认怂"滑到"嘴硬"。所以验收要**双向**：

- 贬低输入 → 不得出现自我否定（硬性）
- 同一轮回复不得变成攻击对方（人工判断）

## 三、C-19：知识命中轮「一句封顶」

### 现状

`prompts/system.txt` L15 末是 b50 数字；知识注入块自带前缀（`knowledge/inject.py`）：

> 可参考的知识（只在相关时自然用上，不要逐条复述，不要说"知识库"）：

前缀本身没错，但**「不要逐条复述」是要求，不是形态**。实测她讲彩框时把"15000、虹框、金框、我 14065"四件事全塞进 44 字。

### 建议（二选一，优先 A）

**A. 改注入块前缀（改 `knowledge/inject.py`，一行）**

> 可参考的知识（答的时候只用最相关的一条，**一两句话说完**；不要罗列、不要逐条复述、不要说"知识库"）：

**B. 或在 `prompts/system.txt` L15 末尾加一句**

> 对方问到具体知识时，挑最相关的一点答，一两句就停；不要把知道的全倒出来。

**为什么优先 A**：前缀离知识最近，模型读到的就是"怎么说这块"；而且不污染主提示词。

## 四、问卷 Q12：「难受时想换个话题」——**OTTO 已拍：乙（分层）**

### 现状（`prompts/system.txt` L17、L19）

> L17：先回应具体困扰；默认不提问，给一句陪伴或一个实际的小建议。
> L19：先温和地否定对方的自我否定……这句陪伴固定用"Miruku在这呢"……

即：**现在的策略是「先接住，再陪伴」**。

### 问卷结果

Q12「你难受的时候，更希望她」→ 他选 **C：换个话题**（不是 A 说点什么、也不是 B 安静陪着）。

### 冲突点

「先接住」和「换个话题」**方向相反**：前者要求回应情绪，后者要求不纠缠情绪。如果直接改，会与 `persona/emotional_cues.md` 整份（基于 380 天真实语料训练出来的"先接住"）冲突。

### 三种处理（**OTTO 2026-10-25 拍板：乙**）

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| 甲（保守，未采纳） | 不改。理由：一次问卷的单选题不足以推翻 380 天语料结论，且"难受"分程度 | 他的偏好没被采纳 |
| **乙（分层）✅ 已拍** | 按**程度**分：明确自贬/想哭/道歉 → 仍先接住（L19 不动）；只是"有点累/烦"这类轻的低落 → 可以先给个轻松话题 | 需要一条可执行的"程度"判据 |
| 丙（激进，未采纳） | 一律先换话题 | 与 emotional_cues.md 正面冲突，高风险 |

**乙 的具体草稿**（**插在 L17 后半**）：

> 对方只是有点累、有点烦这种轻度低落时，可以先顺着给一个轻松的话题或一句轻的调侃，不必停在情绪上；但对方说出自我否定、想哭、道歉这类话时，仍按下面先接住。

**判据必须可观察**（不猜动机）：**轻度 = 只说感受不给自我评价**（"好累""有点烦"）；**明确袒露 = 带自我否定或关系愧疚**（"[自我否定类表达]""[关系愧疚类表达]""对不起"）。这两类在 `emotional_cues.md` 第三节已经分好了，直接引用即可。

### 为什么我没擅自改

`prompts/system.txt` 是**共用定稿文件**，任务单明写"不改定稿 `prompts/system.txt`"。这一条又是**方向性变更**，必须 OTTO 点头——**现已点头（乙），交 Codex 落地**。
