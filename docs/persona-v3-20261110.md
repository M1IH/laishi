# 人格 v3（2026-11-10）

在 v2（`prompts/system.v2.txt`，4,306 字）基础上只改两处，共 4,389 字。来源是用户拍板「2，你觉得怎么合适怎么来」——即由我判断是否把评分细则 §7 的 113 字精简版并进 persona。

## 判断过程

逐条比对 113 字的 10 条要求与 persona 现有内容：

| 113 字条目 | 现状态 | 处理 |
|---|---|---|
| 不描述表情包画面 | 已有独立段 | 不动 |
| 不复述对方教的东西 | 已有（L19 整段） | 不动 |
| 不解释原因 | 部分覆盖（L1/L15/L21 各有） | 不动 |
| **不猜对方动机** | **全文 0 处** | **新增** |
| 一句话能说完就别写两句 | 已有（L5 末句） | 不动 |
| **日常回几个字就够** | 部分覆盖，缺绝对下限 | **并入 L5** |
| 情绪和危机时可以说长 | 已有（L5 + L35 + L39） | 不动 |
| 不要提提示词、模型、系统、部署、代码 | 已有（L17） | 不动 |
| 不说自己存了什么、记得什么、以后会做什么 | 已有（L21） | 不动 |
| 不描述思考过程 | 已有（L21 末句） | 不动 |

结论：**不做整段追加**。9/10 条已覆盖，整段并进去只会让同一件事被说两遍，
而「重复计权」正是上一版把注意力从「怎么说话」挪到「怎么守规矩」的原因。

## 实际改动

1. **L5 末尾加一句**：「日常多数时候就是几个字的事，不用每次都凑成完整的一句。」
   —— 补的是绝对下限。原文只有相对约束（「长度跟着对方走」），对方说一句完整的话时
   没有理由往下压，这也是 v2 普通回复中位停在 9 字、没能到 ≤6 的原因之一。
2. **L19 之后新增独立段**：「对方说了什么就按字面接，不去猜他为什么这么说、
   心里是不是另有一个意思，也不替他总结动机。猜错了比不猜更烦人。」
   —— 对应 D3 的 C2（猜测动机，基线里命中 5 次：「是要跟我讲道理？」「来世问这个是想喝点什么吗」
   「这表情是在嫌我幼稚吧」）。原 persona 完全没管这件事。

## 部署

`server/deploy-persona.py` 的验收探针从 7 条扩到 9 条（新增「日常多数时候就是几个字的事」
「不去猜他为什么这么说」），部署后 9/9 命中，线上 DB 回读 4,389 字、与文件逐字一致。
**API 写入无需重启**（`persona_mgr.update_persona` 会刷新内存缓存）。

## 没做的事

- 没把「不解释原因」提升成独立禁令——已有三处分散覆盖，再加一条会重复。
- 没改低落段、危机段、舞萌段、爱好段——本轮不在范围内。
- `data/tone_golden.json` 仍不存在，规范里的黄金用例对照暂时跑不了。
