## 二、与 v1.0 的差异

v1.0 的 D1/D2 逐档扣分在真实分布上直接扣穿（D1 −48/满分 20、D2 −48/满分 15），两条基线都是 D 级、且再差也还是 0 分。v1.1 改线性归一 + D3/D4 按百回合折算后：

- 最近 100：57 D → **76 B**
- 全量 512：28 D → **61 C**

## 三、实测分布（572 个 bot 段落）

| 指标 | 实测 | v1.1 目标 | 判定 |

## 五、下一步的改进优先级

按扣分幅度排序，改这些收益最大：

1. **句号率 7.0% → ≤1%**（D2 扣 3.4~6.9 分，是单项最大扣分）：`prompts/system.txt` 里没有任何关于标点的约束，属于纯遗漏。
2. **≤10 字占比 47% → ≥85%**（D1 扣 3.5~4.1 分）：对应 prompt 精简版第 2 条「一句话能说完就别写两句」——**该条尚未进 persona**。
3. **中位长度 11 → ≤6 字**（D1 扣 2.9 分）：同上，需靠 prompt 精简版落地。
4. **C3「这张」类表述 11 次**（D3 扣约 15 分）：prompt 精简版第 1 条已含「不描述表情包画面」，需确认是否已进 persona。
5. D4 与 D5 已接近满分，暂不需要动。

> 结论：**prompt 精简版 113 字尚未写进 `prompts/system.txt`**，这是当前最大的一块未落地改动。落地后重跑本评分即可验证收益。
