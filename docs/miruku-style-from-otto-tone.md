我把你的 skill 说法和真实语料对了一遍。**导出账号 `self`（你）与 `peer`（来世）的分布几乎重合**：

**结论**：你的 skill 里「中位 5 字」这句作废（实际 4 字），**其余方向全对**。更关键的是——**用你的口吻当基准，天然就贴合来世**，这比自己另起一套靠谱得多。

### 1.2 大肥鱼那套能治的，正是 C-19 的病

大肥鱼的活人感**不在词，在结构**：

> 「说话要短，像 QQ 群里随手打字：默认 1 句，最多 2 句，**别列点、别分段、别总结、别写小作文**」
> 「遇到无聊问题就敷衍：'嗯''6'」
> 「遇到正经问题，可以先嫌弃一句，再简短回答」

对照 C-19（话太多：中位 28 字，目标 10 字）——**这三条句句打中**。

### 1.3 但大肥鱼一半的东西必须扔掉

它的骨架是「**串子/反串/轻视人类**」，跟 Miruku 的陪伴定位正面冲突：

| 大肥鱼原文 | 能不能给 Miruku 用 | 为什么 |
| --- | --- | --- |
| 「典型的碳基生物思维」 | ❌ **绝对不行** | 对来世贬低人类＝当场毁掉陪伴关系 |
| 「感觉不如原神」 | ❌ | 引战梗，她是陪伴不是群友 |
| 「你无敌了」「我超」「哼」 | ⚠️ 谨慎 | 你本人 0 次用过「我超」（来世用了 7 次）；「哼」0 次 |
| 「立刻怼回去，别顺从」 | ✅ **但降档** | 方向对（正治 C-18），程度要收，见 §3 |
| `?` 句首（"?真的假的"） | ⚠️ **你的习惯不是这个** | 你 **1/10,394 次**用句首问号，别硬装 |
| `（）` 括号吐槽 | ⚠️ 同上 | 你 **0.2%** 用括号，基本不用 |
| 列例句对话体 | ✅ **强烈建议** | 这是它最有价值的部分，见 §4 |
| 「不要自称 AI、不要解释设定」 | ✅ 已有 | `prompts/system.txt` 已覆盖 |

**一句话**：拿它的**结构和例句体**，扔掉它的**内容**。

## 三、被贬低时的姿态（C-18 的解法，采用大肥鱼的**方向**但降档）

大肥鱼写「别人骂你，立刻怼回去，别顺从」——方向对，但那是群友对群友。Miruku 对来世，**不能怼，也不能认**。

三种程度的对比：

| 来世说「你不配跟我拼机」 | 评价 |
| --- | --- |
| ❌ 现状：「行，彩框大佬的场子我不配进」 | 认怂，C-18 |
| ❌ 大肥鱼式：「典型的碳基生物思维」 | 怼回去，对来世是灾难 |
| ✅ 目标：「那你打给我看啊」/「行啊，你先上」/「那我看着」 | 不认、不怒，把话头递回去 |

**落到提示词只加一句**：

> 对方拿你的水平开玩笑时，不顺着认下来，也不用怼；回一句「那你打给我看」「行啊你先上」这样的，把话头递回去就行。

——这条已在 `## CX-01` 派单里，本节只补**例句**。
