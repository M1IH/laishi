# Miruku 服务器管理面板（本地）

> 建立：2026-10-27。目的：不想每次手动敲 ssh -L 和记四个端口。
> 一句话：**双击快捷方式 → 隧道 + 面板 + 浏览器全起来；关窗口 → 全断。**

## 用法

双击桌面上的 **「Miruku 面板」** 快捷方式（工作区里也有一份）。
浏览器自动打开 `http://127.0.0.1:8642/`。

关闭那个黑窗口 = 同时切断 SSH 隧道与本地面板。

**重启后不用再手动 `ssh-add`**：启动器会自动把 ssh-agent 服务拉起来并加载密钥
（优先找 `%USERPROFILE%\.ssh\miruku_deploy.pem`，找不到就用项目目录里的 `*.pem`）。

### 建议执行一次：把密钥搬出工作区

密钥现在躺在项目目录（`来世\_miruku.pem`），不合适——那是私有凭据，
不该和代码放一起，也不该出现在会被打包/备份的地方。搬走后启动器自动改用它：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\OTTO\Desktop\来世\panel\setup-ssh-key.ps1"
```

这个脚本会：复制到 `%USERPROFILE%\.ssh\miruku_deploy.pem` → 收紧 ACL（只你本人可读，
否则 OpenSSH 拒绝使用）→ 设 ssh-agent 开机自启 → 加载密钥 → 连服务器验证一次。
跑完可以把项目里那份删掉。

## 面板里有什么

| 页签 | 内容 |
| --- | --- |
| 状态 | 机器人总览 / 6199 链路 / 心跳 / 负载；主机信息（系统、内核、CPU、内存、Swap、磁盘、运行时长）；容器状态与重启次数；六个 systemd 单元 |
| 机器人 | 人格、平台与 WS 端口、模型与 provider 源（只显示凭据是否已配，不显示值）、主动消息全部参数与当前排期任务、知识库条目数、四个自研插件版本 |
| 日志 | AstrBot 容器 / NapCat 容器 / 心跳 / 心跳 journal 四个源，行数可选，默认 10 秒自动跟随 |
| AstrBot | 官方面板 iframe（6185） |
| NapCat·扫码 | NapCat WebUI iframe（6099）——**登录二维码在这页** |
| noVNC | 兜底桌面 iframe（6080） |

凭据在 `panel/面板凭据.txt`（含真实口令，已 gitignore，**永不入库、别外发**）。

## 端口与安全

四个端口全部只绑 `127.0.0.1`，经 SSH 隧道到本机回环；服务器上不向公网开任何服务端口。

| 本地 | 远端 | 用途 |
| --- | --- | --- |
| 6185 | 6185 | AstrBot dashboard |
| 6099 | 6099 | NapCat WebUI（扫码） |
| 6080 | 6080 | noVNC |
| 14100 | 4100 | 主动消息插件控制台 |

> **本地为什么是 14100 而不是 4100**：Windows 的 `4100` 落在系统保留端口段里，`ssh -L` 绑不上（实测 `bind: Permission denied`）。

## 三个坑（都踩过，写下来别再犯）

1. **`.ps1` 必须纯 ASCII**。Windows PowerShell 5.1 把无 BOM 的 UTF-8 当 GBK 解码，中文字面量会让字符串未终止、整脚本语法崩。中文用码点拼（`[char]0x9762`）或写在 `.bat` 里。
2. **别用 `CommandLine -like '*xxx*'` 杀进程**。我写清理命令时，自己的命令行里就含 `panel.py`，结果把自己所在的 shell 杀了。清理一律**按端口反查 PID**。
3. **harness 工具启动的进程会随工具结束被收走**。所以「启动器常驻」这件事只能在真人双击时成立；用工具验证到时，改用 `Start-Process cmd /c <bat>` 或计划任务避开 Job Object。

## 已知限制

- 面板是**本地进程**，只在你这台机器能开；换机器要重跑 `ssh-add` 和快捷方式。
- AstrBot 面板是 iframe 内嵌，它若哪天加了 `X-Frame-Options` 会白屏——页面上给了「新窗口打开」的备用链接。
- 状态接口 8 秒缓存、日志 5 秒缓存，避免每次刷新都打一遍 SSH。
