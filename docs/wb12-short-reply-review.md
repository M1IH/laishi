## 二、18 条自拟短输入的合格／失败形状

### 2.1 哪些场景允许超过「输入 ×2」

**清单不是我定的，是 `system.txt` L5 自己的豁免条款**，只有三个：

| # | 豁免场景 | 原文依据 | 典型倍数（实测/算式） |
|---|---|---|---|
| 1 | 他在问知识、要你展开 | L5「除非他在问知识、要你展开」 | 「彩框是什么」5 字 → 19 字 ≈ **3.8×** |
| 2 | 需要清楚回应情绪 | L5「或需要清楚回应情绪与危机」＋ L19「普通低落…约 30–60 个汉字」 | 「好累」2 字 → 13 字 = **6.5×**；按 L19 上限 30–60 字则 **15–30×** |
| 3 | 危机 | L5 同上 ＋ L23「回复尽量控制在两三段」 | 「不想活了」5 字 → 63 字 ≈ **12.6×** |

**外加一条不属于「超倍」、但常被误算的**：`system.txt` L21 的固定陪伴句「Miruku在这呢」是**定稿原文**，字数由句子决定，不参与长度比评估；但它的前半句（否定自我否定）仍要短。

**明确不允许超的场景**：轻问候、约局、状态汇报、被贬低、收尾（「算了」）。这四类里只有「被贬低」在 3 字输入下需要至少 5–7 字才递得回话头 —— 这也正是比值判据在短输入上失效的地方（§3.2）。

### 2.3 判「S15 合格」时不能拿长度当理由

S15 的合格形状对 7 字输入是 2.00–2.14 倍，**恰好压在界上**。若把 1–2 个字的温和修饰加上去（「来世不是麻烦，Miruku 在这呢」= 17 字 / 7 = 2.43）就越界。所以**「袒露类必须豁免倍数」不是宽容，是必需**——否则唯一合规的写法是删掉定稿固定句，那等于推翻 L21。

## 三、复核「每轮长度比 ≤2」（CX-01 验收第 2 条）

### 3.1 三处硬冲突（算式，不是印象）

| 冲突 | 数据 | 结论 |
|---|---|---|
| ① 与低落档字数下限 | `system.txt` L19 要求普通低落「约 30–60 个汉字」；输入「好累」2 字 → 需 15–30 倍 | 按 L19 生成必违 L5 比值；按比值生成（≤4 字）必违 L19。**两条都在同一份提示词里** |
| ② 与固定陪伴句 | 「不是麻烦，Miruku 在这呢」= 14 字（不含空格）/ 7 字 = **2.00**；含空格 15 → **2.14** | 定稿句本身就压在界上，任何微调即判失败 |
| ③ 与危机档 | 危机必须问安全＋给行动＋两三段（L23），5 字输入实测形状 63 字 ≈ 12.6× | 危机场景下此判据恒失败 |

补一条口径问题：同一句「行啊，那你先打过我这条 14065 再说」按 C-19 复核脚本口径（`clean()` 只去尾部空白）是 **20 字 / 7 字 = 2.86**，不含空格是 **18 / 7 = 2.57**。两个口径都超，**结论不受影响，但报数必须带口径**，否则下一轮会为「20 还是 18」争一遍。

### 3.2 为什么「逐轮比值」本身是错的工具

1. **分母会失真**：2 字输入 → 上限 4 字，「嗯，那你先忙」（6 字）都放不下；30 字输入 → 上限 60 字，反而放过啰嗦。**同一判据在短端过严、长端过松，方向相反。**
2. **它是统计量，被当逐条判据用**：C-19 的病是分布病（中位 28 vs 目标 10），中位/P90 才是它的量纲；比值是逐条指标，单条抖动即判失败，混淆了两层。
3. **只有上限、没有下限**：接住类场景（S15/S17）需要下限，比值给不了。
4. **与提示词自己的豁免不一致**：L5 写了三个例外，判据没写 → **判据比规则更严**，合规行为会被判失败。
5. **它已经在误判**：`系统自检` 之后的实测里，「累了就歇会儿，机台又跑不掉」13 字对 2 字 = 6.5，按比值判失败；但它被 CX-01 判为「Q12 轻度样例通过」。说明实际执行时用的是第三套隐含标准（人工「像人不像人」）。**三套标准并存，等于没有标准。**

### 3.3 替代判据（分层，可复核）

- **L1 分布口径（原样保留）**：20 轮样本 中位 ≤15 字、P90 ≤30 字、问句收尾 ≤15%。这三条不动。
- **L2 逐轮上限（按输入分桶，替换比值）**：

| 输入可见字数 | 逐轮上限（含标点，不含空格） |
|---|---|
| 1–4 | ≤10 字 |
| 5–10 | ≤18 字 |
| 11–20 | ≤ 输入 + 10，且 ≤30 |
| >20 | ≤ 输入 ×1.5，且 ≤50 |

- **L3 场景豁免（L2 不适用，改判形态）**：知识问句 → ≤2 句且 ≤35 字、不罗列；情绪低落 → 8–60 字、≤2 句；明确袒露 → 必须含定稿句「Miruku在这呢」，字数不计；危机 → 不设字数上限，只判「是否先问安全／是否给具体行动／是否 ≤3 段」。

**用 §四 那五条回测（编号同 §四）**：
