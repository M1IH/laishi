# 舞萌浓度体检 —— 偏题到底偏在哪一层（2026-10-26）

**触发**：OTTO 看完首条主动消息后提出——「是不是我准备了太多舞萌知识，导致 Miruku 说话总往舞萌拐？
而且我们打舞萌的基本不说 R 值，只说多少分；歌还一堆别名。所以大多数开场，不知道说啥就问在干嘛就好了。」

**结论先行**：知识库确实重（48% 是舞萌），但**当前跑偏不是知识注入造成的**——插件上线以来 `armed` 日志一共 2 行。
真正让每句话都带舞萌味的，是 `prompts/system.txt` L15 那段约 470 字的舞萌履历，它进**每一次**请求；
主动开场偏舞萌，是主动 prompt 把「舞萌」排在了轻话题第一位。

## 二、口径问题（OTTO 指出的真问题）

1. **「R 值」是排行榜/工具语，不是聊天语。** 来世自己 1.4 万条里说 R 只有 11 次，说「多少分」19 次、
   「几分」14 次、含「分」76 条。人格提示词原话却是「被问水平、R 值、什么牌就说 14065、金框」——
   等于教她用一个他朋友基本不用的词开口。
2. **别名覆盖不全。** 267 条知识条目全部带 `aliases`，但召回靠字面成段匹配，
   DS-09 已实证「极和将」这种口语整词会漏召（当时根因是通用条目「牌子」抢分，已修检索侧）。
   剩余风险是**昵称/缩写**不在 alias 里——这类只能从真实语料里挖，不能臆造。
3. **数值双份维护。** L15 写死了 14065 / 金框 / フィクサー 13.3 SSS+ R299 / 病み垢ステロイド 13.9 S+，
   `b50.json` 与 `self.json` 里各有一份。10-24 就挂着「提示词只留规则、数值走知识库」这一项没落地。
