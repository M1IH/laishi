# 来世问卷（T0）· 设计说明与可发送版

> 设计：DeepSeek　日期：2026-10-25　任务来源：来世本人主动提出「可以给个调查问卷，帮助优化人格/对话」
> 边界：本文只出问卷，不改 `prompts/`、`persona/`、运行配置，不发 QQ。**发送与回收都由 OTTO，AI 不代发、不代读答案**（沿用 D3：首周正文 OTTO 自看）。

---

## 一、先定三件事（不先定这三件，问卷一定白填）

### 1. 谁来发：**OTTO 发，不走 Miruku**

不要让她在聊天里问「你觉得我哪里不好」。四个理由，每一个都足以否掉：

| 理由 | 依据 |
| --- | --- |
| 会直接制造「问卷感」 | C-13 就是「连续追问/问卷感」，`defect-register.md:197`；她连问就是同一个病 |
| 违反 persona 的核心禁令 | `persona/miruku.md:11`：**不做"完整人设说明书"**，「她是一个人，不是一个需要自我介绍的物件」；`docs/casual-conversation-acceptance.md` §2-A′-2：**不接"是不是 AI"这个问题** |
| 答案会污染被测对象 | 问卷内容进了她的历史，下一轮她就会「知道自己正在被评分」，后续对话全部不可用于观察 |
| 24h 观察期会被打断 | 多轮问答会改变自然节奏，`docs/soak-watch-card.md` 的段与链路统计会被搅乱 |

**正确通道**：OTTO 用 QQ / 微信 / 当面，把下面「四、可发送版」当纯文本发给他。答案随便写在哪，回给 OTTO。

### 2. 什么时候发：现在发 T0，**一周后同题再发一次**

同题复测才有信息量——单次只能知道「此刻他烦什么」，两次才知道「我们改的那一条他有没有感觉变化」。所以题目要**固定**，不要每次换。

### 3. 结果怎么处理：只给 OTTO，不贴仓库、不喂给她

- 答案里有他的原话和真实感受，属于第三方隐私；`.gitignore` 已经把 `个性化语言/聊天记录/` 排除在外，问卷答案同理**不进仓库**。
- **绝对不要**把他的话转述给她（「听说你希望我短一点」）——那是最快地毁掉陪伴感的做法，也是 persona 明令禁止的自我说明书。
- 本文件只留**问卷模板与设计理由**，不含任何他的作答。

## 二、设计取舍（为什么是 14 题、为什么这么问）

### 2.1 硬约束：他的文本中位 4 字

`persona/tone_profile.md:23`：目标方可读文本中位 4 字、约 98% 不超过 15 字、句号约 0.1%。

⇒ **40 题的里克特量表会被答成「还行/都挺好」**，或干脆不填。所以：

- **总题量 ≤ 15**，目标 **8–10 分钟填完**；
- **能选字母就别让人写句子**（写作成本高 → 弃填）；
- **每题都允许空着**，且开头就说清楚「跳过没问题」——不设必答，否则他会为了完成而编。

### 2.2 问行为，不问评价

「你觉得她像人吗」这种题只能换回礼貌话。可执行的是**具体时刻**：

> 「有没有哪一句让你突然觉得『这不太像人』？」

这一题的信息量高于任意十道打分题，因为它指向一个可定位的句子，而句子能改。

### 2.3 用昨晚的真实片段当锚点

抽象问题（「语气自然吗」）他会答「还行」；把昨晚的原句摆出来问（「她答『彩框大佬的场子我不配进』时你什么感觉」），他会立刻有反应。

锚点只用**她**的台词（项目产出物），他的原话只做泛化描述（「你开玩笑说她不够格跟你拼机」），避免把他的话搬进文档。

### 2.4 不问技术问题

命中率、注入块、分段策略他判断不了；问了只会得到猜测。题面里**不出现**插件名、模型名、提示词、"prompt"这类词。

### 2.5 每道题都要能落到一个可改的文件

见第五节映射表。落不到的题不放进问卷。

## 四、可发送版（以下整段可直接复制发给来世）

> 发给来世时，**只发这一段**；上面三节是我们内部的设计说明，不要带上。

```text
想请你帮个忙，填个小问卷，8 分钟就能填完。

先说清楚：
· 这不是考试，没有必答题，跳过完全没问题
· 你写的只用来看她哪里说得不对，不会拿去喂给她，也不会让她说"听说你觉得我……"
· 不用替她说好话，觉得烦就说烦，说烦比夸她有用

能选就选一个字母，想补一句就补，不想补就空着。

一、体感

1. 她回你的长度大概是 20–40 字，你平时是几个字
   A 正好　B 想再短点　C 可以再长点

2. 她经常用问句收尾（"你 R 值多少了""手热不热"）
   A 正好　B 有点多，像在采访我　C 太少，想让她多问点

3. 她主动讲自己的事（"我这 14065 还在金框蹲着"）
   A 喜欢，像真有人　B 有点多，抢我的话了　C 太少，想听她多说

4. 你开玩笑说她不够格跟你拼机，她回"彩框大佬的场子我不配进"
   A 没什么感觉　B 有点别扭，她没必要贬低自己　C 挺好，有来有回

5. 她讲知识点的时候（"彩框就是 R 值 15000 以上的虹框"）
   A 挺自然　B 像在念百科　C 太少，希望她懂更多

二、具体时刻（一句话就行，想不出就空着）

6. 有没有哪一句，让你突然觉得"这不太像人"？
7. 有没有过"算了不说了"的时候？当时她在说什么？
8. 有没有什么她该记住、结果忘了的？
9. 她有没有哪种收尾或口头禅让你烦？
10. 有没有一句话你想听她说、但她从来没说过？

三、边界

11. 有没有什么话题，你希望她永远别主动提？
12. 半夜或者你在忙的时候收到她消息：
    A 挺好　B 别在这个点　C 看内容
13. 你难受的时候，更希望她：
    A 说点什么　B 就安静陪着　C 换个话题

四、收尾

14. 如果只能改一件，改哪一题？（填题号）
15. 一句话，随便说
```

## 五、给 OTTO 的操作提醒

1. **别转述他的答案给她看**，也别问「你觉得你哪里不好」——见 §一-3。
2. **回收后先别急着改**：等一周 T1 复测完再动 `prompts/`，否则 T1 比不了。
3. **如果 Q4 选了 B**，说明昨天那个「自我贬低」坐实了，我会补登进 `docs/defect-register.md`（编号顺延），并按 §三 的映射改 `prompts/system.txt`。
4. **如果 Q2 选了 B**，直接接 C-13——那不是新问题，是同一个缺陷被第二个人证实。
5. 问卷里 **Q11/Q12 涉及主动消息**，属于另一条线（`docs/soak-watch-card.md` 观察期），收到答案先记下，不要在观察期内改配置。
6. **答案不要贴进本仓库**（含他的原话），只在本机留着比对 T0/T1。

## 六、这一版刻意没做的事

- 没做长量表（会弃填）；
- 没问「你觉得她像人吗」（只能换回礼貌话）；
- 没让他评价技术指标（他判断不了，问了是浪费）；
- 没让 Miruku 出场问（见 §一-1）；
- 没做在线表单（多一个中转，多一份隐私风险，纯文本最快）；
- 没在题里出现任何插件名、模型名、"AI"、"提示词"字样。
