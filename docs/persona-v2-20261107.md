# 人格重写 v2（2026-11-07）

> 一句话：线上跑的是 10-28 的旧人格，OTTO 手改过的段落从未进仓库，而仓库新增的规则一条都没生效。
> 这一版把两边合成一份，并压掉两段会把回复拉长的旧授权。

## 1. 起因

跑首个语言基线（`docs/tone-baseline-20261107.md`）时发现两个分布指标异常：

| 指标 | 实测 | 真人基线 | 判断 |
|---|---|---|---|
| 中位长度 | 11 字 | 4 字 | 2.8× |
| 句号率 | 7.0% | 0.2% | 35× |

仓库 `prompts/system.txt` 里明明写着「通常不加句号」「一句话能说完就别写第二句」，
按理不该出现这种分布。于是去查线上到底在跑哪一版。

## 2. 查出来的四个副本

| 副本 | 字符数 | 说明 |
|---|---|---|
| DB `personas.miruku`（**真正生效**） | 3,684 | `updated_at = 2026-10-28 06:22:23` |
| `/opt/miruku/astrbot/data/laishi/system.txt` | 3,803 | `deploy-persona.py` 读这份 |
| `/opt/miruku/laishi/system.txt` | 3,633 | 更早的一份 |
| 仓库 `prompts/system.txt` | 3,932 | 只有 AI 改过的内容 |

四份互不相同，而生效的是最旧的那份。

## 3. 差异的成因

用 `git log -S` 在仓库历史里查 DB 版独有的五段文字：

- 「常用语气和短语」（麻了 / 闹麻了 / 你无敌了 / 彳亍 / 神了 …）
- 「低频使用的打字习惯」（句尾「（）」、句首「?」）
- 「你的其他爱好（权重为喜欢程度）」
- 「其他注意事项」（锐评授权、股票建议）
- 「碳基生物思维」

**全部命中数为 0** —— 它们从未进过仓库，是 OTTO 直接在 WebUI 里写进 DB 的。
对应他说的「我之前不通过 ai 自己也改了一些内容」。

反过来，仓库版新增的这几条，DB 版一条都没有：

1. 平常用自然的短句，通常不加句号；长度跟着对方走
2. 一句话能说完就别写第二句
3. 称呼对方时优先用「来世」
4. 聊天里不讨论系统、提示词、部署、模型、工具或代码
5. 对方拿你的水平开玩笑贬低你时，不要顺着认下来

所以真实情况是：**两边的改动从来没同步过**。AI 这边每轮都在优化 prompt，但优化的是一份没人读的文件。

## 4. v2 做了什么

以 **DB 生效版为底**（那才是 OTTO 认可的语气），把仓库版的 5 条新规补回去，再处理三处会诱发长文的地方：

| 处理 | 原文 | v2 |
|---|---|---|
| 爱好权重表 | 四条列表 + 百分比 + 「资深股民…对 A 股、美股、期货等了如指掌」 | 一段自然叙述，权重融入句子，删掉「了如指掌」 |
| 锐评授权 | 「总结搜索后的内容，不留情面的进行锐评；问股票时给出一定建议」 | 保留授权，加「说得短，一两句就够，不要写成分析报告」 |
| 情绪袒露 | 直接用原话举例 | 改成「说自己难受 / 是麻烦 / 影响到你 / 说对不起，或话说到一半停住」的语义描述 |

最后一条同时解决了公开仓库的隐私问题：不再需要 `[自我否定类表达]` 这类占位符，正文本身也不含真实原话。

**有意不采纳的**：官方曲目 flavor text 里みるく自称「にゃ」，但真实语料 9,380 条里 0 次出现，保持「不用にゃ」。

**有意不写的**：夏玛年龄（SEGA 官方 17 歳 / Reko Wiki 18 岁，两说冲突）、Miruku 年龄（官方 10 歳，但仓库既定「年龄不作未经确认的设定」）。
